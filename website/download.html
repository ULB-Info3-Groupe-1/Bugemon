Téléchargements

Pour construire le JAR :

mvn clean package

Pour exécuter le jeu :

mvn javafx:run

Si vous voulez lancer la base de données localement :

docker compose up -d

Le JAR (s'il est généré) sera disponible dans target/. Vous pouvez aussi consulter le code source dans src/.
