Comment jouer

Le jeu se lance avec JavaFX. Pour démarrer l'application localement :

docker compose up -d   # démarre la base Postgres
mvn clean javafx:run   # lance le jeu

Contrôles & Principes

Le jeu est en JavaFX — utilisez l'interface graphique pour naviguer entre les menus, gérer l'équipe, et entrer en combat.

Données du jeu

Les listes d'attaques, objets et Bugémons utilisés par le jeu sont exposées dans src/main/resources/json/ et sont intégrées dans ce site pour exploration.
