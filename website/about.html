À propos du projet

Bugemon est un RPG développé en Java/JavaFX dans le cadre du cours INFOF-307. Le projet inclut un système de combat, un inventaire, un arbre de compétences et la persistance via une base de données (Postgres).

Prérequis

  • Java 21
  • Maven
  • Docker (pour la base de données)

Fonctionnalités

Combats stratégiques, progression des Bugémons, inventaire, et plus. Voir le README pour les détails complets.
